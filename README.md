# 것모닝 시상 룰렛

2026 것모닝코리아 팀 챌린지 · Dream US 시상 추첨용 웹앱 (두근두근 룰렛 2.0).

- `sian.html` — 화면 원본 (Claude 아티팩트 시안과 같은 파일)
- `index.html` — 설치형 앱. `python3 build.py`로 sian.html에서 만든다
- `sw.js` — 오프라인 저장. 배포할 때마다 `VERSION`을 올린다
- 상품 사진: 암웨이 카탈로그 2026 가을호(VOL.75), 로고: gutmorning.co.kr

행사 후에는 참가자 이름이 들어 있으므로 저장소를 삭제한다.
